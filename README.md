I am an Electrical Engineering undergraduate at K. N. Toosi University of Technology and an Undergraduate Research Assistant at ARAS Laboratory.

My interests include computer vision, medical image analysis, generative models, and robotics perception.

## Updating the website

- Edit `index.html` to update the main page and project descriptions.
- Edit `contact.html` to update contact information and profile links.
- Edit `styles.css` to adjust the design and motion.
- Add images and documents to `assets/`.
- Replace `assets/Yazdan_Bayat_CV.pdf` to update the downloadable CV.

## Publishing

The website is hosted on GitHub Pages from the `main` branch, using `/ (root)` as the publishing folder.

Commit changes to `main` to update the website automatically. No installation or build commands are required.
