01 / MEDICAL IMAGE ANALYSIS

Cataract surgery
difficulty assessment

Using surgical microscope images to assess cataract severity and pupil dilation, with the aim of adding case-difficulty context to surgeon-skill evaluation and surgical training.

Medical AIComputer vision
Read project details +

The idea. A surgeon’s performance needs to be interpreted in the context of the case. This project investigates visual indicators of case difficulty that could help a skill-assessment system account for the conditions under which a procedure is performed.

The approach. Surgical microscope images are used for two complementary tasks: four-class cataract severity classification and binary poor pupil dilation detection. CNN and transformer models learn visual patterns associated with these factors.

Intended use. Providing a case-difficulty signal for future surgeon-skill assessment, training feedback, and research into surgical performance.

My work. Dataset creation and annotation, preprocessing, video-identifier mapping, and model development and evaluation.

Sign language,
represented as motion.

A collaborative comparison of RGB-based Swin Transformer and skeleton-based ConvBiLSTM approaches on WLASL ↗.

Computer visionSequence learning
Read project details +

The idea. Recognizing individual signs from video is a visual sequence-learning problem. This collaborative project compares image-based and landmark-based representations.

The approach. RGB-based Swin Transformer and skeleton-based ConvBiLSTM models are explored using the WLASL dataset.

Team. Yazdan Bayat, Mobina, and Iman.

03 / ENGINEERING PROJECT

Finding structure
in the visual world.

A ROS image-processing node with Canny edge detection, live parameter tuning, and RViz visualization.

ROSOpenCV
Read project details +

The idea. Turn camera images into an edge representation that makes image structure easier to inspect within a robotics workflow.

The implementation. An OpenCV-based Canny node in ROS 1 Noetic subscribes to camera images and publishes edge outputs. Dynamic reconfigure supports live parameter tuning, with both views displayed in RViz.
